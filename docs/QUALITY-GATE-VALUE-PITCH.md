## 页面结构（3-5 页）

### P1 · 一句话定位 + 场景锚定
- 标题：让模型企业 1 天接入，3 个月省下产品化时间
- 核心图：`你的模型 → PrismCraft 工作流编排 → 模型无关质检层 → 数据闭环（可微调）`
- 锚定场景：动画/短视频生产团队的真实痛点（跨镜角色漂移、批量一致性、导演规则约束）

### P2 · 为什么是"放大"而不是"适配"
| 我们提供 | 你的收益 |
|---|---|
| 43 个业务模块完整工作流 | 不必从零做产品（编辑器/时间线/任务/导出） |
| 模型无关质检层 | **你的模型在这里有确定性场景**（质检即卖点） |
| 13 家提供商集成经验 + 插件体系 | 与主流模型同台对比，差异化可见 |
| 测试 + DDD + 契约驱动 | 接手成本低、AI 协作友好 |

关键页元素：一张"如果自己做 vs 接入 PrismCraft"对比表（时间/成本/风险）。

### P3 · 1 天接入的证明
- 接入 3 步图（JSON 声明 → 请求适配 → 质检冒烟），标注"零代码可完成 60%"
- **DEMO 脚本**（录视频用）：
  1. 0:00-0:40 展示 13 家 provider 列表 + 插件市场
  2. 0:40-1:30 新建 acme-video JSON 插件（现场贴模板）
  3. 1:30-2:30 配置 API key → 快速生成 3 个分镜
  4. 2:30-4:00 QC 面板：rule checker 自动生效 + acme 一致性模型报告
  5. 4:00-5:00 阈值 per-model 配置 + 数据反馈导出
- 验收台词："从零到可用，一个工作日"

### P4 · 数据闭环 = 长期壁垒（给 CTO）
- 反馈数据流：`用户确认/否决 → quality_feedback → 导出 → 微调 → 模型更新`
- 三种模式：纯消费（0.5 天）/ 质检协作（1 天）/ 深度共建（联合微调）
- 强调：我们不训练你的模型，但帮你积累"高质量标注过的训练素材"

### P5 · 接入成本与契约（给 CEO）
- 时间承诺：主体接入 1 天；深度共建按协议
- 技术契约：AGPL + 商业授权边界
- 我们的承诺：质检层 API 稳定（**接口冻结期自 v1.0 正式发布起算 12 个月**，v0.x 草案期不承诺）；能力声明向后兼容
- 结束 CTA：预约 45 分钟 demo / 索取接入指南 / 技术尽调资料包
